## 学習内容

- Day 1: MySQLへの接続と基本操作
- Day 2: テーブルの作成とプレイヤーの登録・更新・削除
- Day 3: WHERE、LIKE、ORDER BY、LIMIT
- Day 4: 集計、GROUP BY、HAVING、ランキング
- Day 5: 外部キー、JOIN、アイテム管理
- Day 6: インデックス、EXPLAIN
- Day 7: トランザクション、バックアップ、最小権限
